## 2. Roadmap page — View tabs + timeline

The current vertical Now/Next/Later columns become the **List** view (default — unchanged visually). Two new tabs sit alongside it.

### 2a. Tab strip

A new tab strip lives **between the hero subtext and the KPI summary cards**, exactly where you described:

```text
Hero
"Derived from WP Engine · 7 pain points scored…"
─────────────────────────────────────────────
[ List ]  [ Kanban ]  [ Gantt ]      ← new
─────────────────────────────────────────────
KPI summary cards (Total · Priority mix · Effort mix · Now bucket)
View body (List | Kanban | Gantt)
Footer (Copy markdown · Export ▾ · Reset)
```

State for the active view is local to `src/routes/roadmap.tsx` (no need to persist across reloads).

### 2b. Quarter timeline (shared across all three views)

Every roadmap item gets a derived `quarter` field (e.g. `Q2 2026`) computed from "today" + the item's bucket. This is a pure derivation, like effort:

- `now` → current quarter
- `next` → current quarter + 1
- `later` → current quarter + 2

When the user moves an item between buckets (in any view), the quarter updates automatically — same reactive pattern as the existing bucket/effort overrides. If the user wants to override the quarter directly, they can: a new `quarter` override key joins `bucket` and `effort` in `roadmapStore`.

The current List-view item card gets one new chip next to `P1 · Reliability · 12 mentions · Effort M`:

```text
Q2 2026
```

…and a small `Quarter ▾` selector joins the existing `Move to ▾` and `Effort ▾` controls so you can push something to Q4 2027 without changing its bucket.

### 2c. Kanban view

Three horizontal columns (Now / Next / Later), each a vertical stack of compact ticket cards. Drag-and-drop:

- Drag a ticket between columns → bucket override updates → quarter recomputes → all views stay in sync.
- Drag within a column → manual order override (a new `order` key in `roadmapStore` per id, sorted ascending; unset items fall back to impact score).
- Each ticket shows: title, priority pill, quarter pill, impact, mentions. Click to expand for evidence (same data as the List card).

Library: native HTML5 drag-and-drop (no new dependency). It's enough for column-to-column and within-column reordering and avoids adding `dnd-kit`.

### 2d. Gantt view

Horizontal timeline, one row per item. The X axis spans **today's quarter through today + 5 quarters** (1.5 years), labelled `Q2 2026 · Q3 2026 · …`. Each item renders as a bar that spans exactly its assigned quarter. Bar colour = priority (P1 destructive / P2 warning / P3 muted), label inside the bar = title (truncated). Hovering a bar shows the full title, mentions, and effort in a tooltip. The "today" line is a thin vertical accent rule.

Gantt is read-mostly in v1: clicking a bar opens the same expand panel as Kanban (evidence + the existing Move/Effort/Quarter selects). No bar dragging yet — that needs a real DnD lib and we don't want to over-build.

### 2e. Roadmap footer export

Same treatment as the Analyze footer: replace the stub "Export PDF" button with an **Export ▾** menu offering PDF and CSV.

- **PDF**: roadmap header + KPI summary + each bucket's items (title, priority, quarter, effort, mentions, rationale, top quote).
- **CSV**: one row per item — `Rank, Title, Bucket, Quarter, Priority, Effort, Impact, Mentions, Category, Rationale, Quote 1`.

"Copy as markdown" stays as a separate button (it's a different use case — paste into Linear/Notion).
